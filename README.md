# FM Price Tracker (Old School Maple)

เก็บราคาของใน Free Market จาก **คลิปที่อัดหน้าจอไว้** แล้วสร้างรายงานราคาย้อนหลัง

> ⚠️ โปรแกรมนี้อ่านแค่พิกเซลจากไฟล์วิดีโอที่อัดไว้แล้วเท่านั้น
> ไม่ยุ่งกับเกม ไม่กดปุ่มแทน ไม่อ่านหน่วยความจำ และไม่ดักข้อมูลเครือข่าย (ตามกฎเซิร์ฟเวอร์: ห้ามบอท/มาโคร)

---

## ใช้งานประจำวัน

### 1. อัดคลิป
- ใช้ Windows Game Bar (**Win+Alt+R** เริ่ม/หยุดอัด) ที่ความละเอียด **1920×1080**
- เดินเข้าร้าน Hired Merchant ทีละร้าน แล้วเลื่อนรายการให้เห็นของครบทุกแถว **จนแถบเลื่อนลงไปสุด**
  (ระบบดูตำแหน่งแถบเลื่อนเพื่อนับแถวที่หน้าตาเหมือนกัน เช่น ยาชนิดเดียวกัน 8 กอง ไม่ต้องเลื่อนช้า แต่อย่าเอาเมาส์ไปค้างบังแถบเลื่อนตลอด)
- อย่าย้ายตำแหน่งหน้าต่างร้าน ให้อยู่ตำแหน่งเริ่มต้นตามที่เกมเปิดขึ้นมา โปรแกรมอ่านตามตำแหน่งตายตัว
- แต่ละแถวควรค้างไว้อย่างน้อยครึ่งวินาที เพราะแถวที่เห็นแค่เฟรมเดียวจะถูกตัดทิ้ง
- อยากได้ชื่อเต็มของไอเท็มที่ชื่อยาวจนโดนตัด ให้เอาเมาส์ชี้ค้างไว้ให้ tooltip ขึ้น

### 2. สั่งรัน `run.bat` (เลือกวิธีไหนก็ได้)
- **ดับเบิลคลิก `run.bat` ใน File Explorer:** ระบบจะหยิบ**คลิปล่าสุด**ใน `Videos\Captures` ให้เอง กด `Y` เพื่อยืนยัน
- **ใน VS Code:** เปิด Terminal (Ctrl+`) แล้วพิมพ์ `.\run.bat` จะได้ผลเหมือนดับเบิลคลิก
- **ลากคลิปไปวางทับ `run.bat` ใน File Explorer:** ใช้กับคลิปที่ไม่ใช่อันล่าสุด
  (ห้ามลากใน VS Code เพราะ VS Code จะย้ายไฟล์ ไม่ได้สั่งรัน)

ระบบจะทำ 3 ขั้นต่อกันเอง:
1. อ่านคลิป ได้ไฟล์ `results\<ชื่อคลิป>\items.csv` ในโฟลเดอร์โปรเจกต์ ตัวคลิปอยู่ที่เดิม (คลิป 2.5 นาทีใช้เวลาราว 4 นาทีบนเครื่อง 8 คอร์)
2. บันทึกลง `fm.db`
3. สร้าง `report.html` **ไม่เปิดเว็บขึ้นมาเอง** (จะได้ไม่เด้งทับตอนกำลังอัดคลิปอื่น)
   บรรทัดท้ายของ log จะมีลิงก์ `open the report: file:///...` ให้กด **Ctrl+คลิก** ใน Terminal ของ VS Code เมื่อพร้อมดู

**วันที่ของข้อมูล** ดึงจากชื่อไฟล์ (Game Bar ใส่วันที่ไว้ เช่น `... 2569-10-15 15-50-50.mp4` ปี พ.ศ. แปลงเป็น ค.ศ. ให้เอง) ถ้าในชื่อไฟล์ไม่มีวันที่จะใช้วันนี้แทน
ถ้าอยากกำหนดวันที่เอง:
```
python ingest.py "results\<ชื่อคลิป>\items.csv" --video "<ชื่อคลิป>.mp4" --date 2026-10-15
python report.py
```

รันคลิปเดิมซ้ำได้ ข้อมูลของคลิปนั้นใน `fm.db` จะถูกเขียนทับ ไม่เกิดข้อมูลซ้ำ
ถ้าอัดหลายคลิปในวันเดียว (หลายห้อง FM) ข้อมูลจะรวมเป็นวันเดียวกันในรายงาน

### 3. ดูรายงาน `report.html`
เปิดด้วยเบราว์เซอร์ได้เลย ไม่ต้องใช้อินเทอร์เน็ต (ถ้าออฟไลน์ ฟอนต์จะเปลี่ยนเป็นฟอนต์ของเครื่อง) ใช้บนมือถือได้ เพราะตารางจะเปลี่ยนเป็นการ์ด
- **ปุ่มประเภท:** ทั้งหมด / Scroll / Dark Scroll / Mastery Book / อื่นๆ
- **ช่องค้นหา:** ค้นได้ทั้งชื่อไอเท็มและ**ชื่อร้าน**
- **ป้าย "ชื่อไม่ครบ":** ชื่อในร้านโดนตัด ระบบยังไม่แน่ใจว่าเป็นไอเท็มไหน (ดู `review_names.csv`)
- **ชี้เมาส์ที่ไอเท็ม:** ขึ้นการ์ด stat แบบในเกม (บนมือถือดูได้ตอนกดที่แถว)
  - stat มาจาก tooltip ที่เห็นในคลิปของคุณเท่านั้น เพราะเซิร์ฟเวอร์นี้ stat ไม่ตรงกับข้อมูล GMS
  - อยากให้ไอเท็มไหนมี stat ให้ชี้เมาส์ค้างที่ไอเท็มนั้นตอนอัดคลิป
  - ของตีบวก (+N) แยกแถวและมีป้าย "ตีบวก" เพราะ stat และราคาไม่เท่ากับของปกติ
- **ช่องค้นหา:** พิมพ์หลายคำได้ เช่น `scroll gloves att`
- **กดหัวคอลัมน์:** เรียงลำดับ
- **กดที่แถว:** ดูรายการของวันนั้นว่าร้านไหนขาย ราคาเท่าไร เหลือกี่ชิ้น
- **ความหมายของแต่ละคอลัมน์**

  | คอลัมน์ | ความหมาย |
  |---|---|
  | Lowest / Median | ราคาต่อชิ้นต่ำสุด / ค่ากลาง ของวันล่าสุด |
  | Listings | จำนวนรายการที่วางขาย |
  | Stock | จำนวนชิ้นรวมที่ยังเหลือ |
  | Sold out | รายการที่ขายหมดแล้ว (แถวจางในเกม) |
  | Daily median | กราฟค่ากลางราคารายวัน เอาเมาส์ชี้ดูตัวเลข |
- **ราคาหลอก (กันร้านปิด เช่น วางยา 1 ขวดราคา 1000m):** ไม่ถูกนำไปคิดราคา นับเป็นราคาหลอกเมื่อ
  - ราคา **≥ 100m และตอนอัดคลิปไม่ได้ชี้เมาส์**ที่ไอเท็มนั้น หรือ
  - ราคา **≥ 999m** (ถึงจะชี้เมาส์ก็นับเป็นราคาหลอก) หรือ
  - แพงกว่าราคากลางของร้านอื่นที่ขายไอเท็มเดียวกันวันนั้น **10 เท่าขึ้นไป**

  **ของแพงที่เป็นราคาจริง ให้ชี้เมาส์ค้างจน tooltip ขึ้นตอนอัด** ระบบจะนับเป็นราคาจริง
  - เปิดสวิตช์ *Include placeholder prices* ถ้าอยากรวมกลับเข้ามา
  - เอาเมาส์ชี้ป้าย "placeholder?" ในรายชื่อร้าน จะบอกว่าโดนเพราะกฎข้อไหน
  - เปลี่ยนเกณฑ์ได้ เช่น `python report.py --placeholder-unhovered 50000000 --placeholder-min 2000000000 --placeholder-ratio 20`

## ดูแลรายชื่อไอเท็ม (ทำเป็นระยะ)

รายชื่อในเกมมักโดนตัดท้ายเมื่อยาวเกินช่อง เช่น `Scroll for One-Handed Axe for Ac` โปรแกรมจึงใช้ `items.json` จับคู่กับชื่อเต็ม

### `items.json`
```json
{
 "items":   ["ชื่อที่เชื่อถือได้ เช่นจากรายชื่อไอเท็มของเว็บ หรือที่เพิ่มเอง"],
 "auto":    ["ชื่อที่ระบบเรียนรู้เองจากคลิป (แก้หรือลบได้)"],
 "aliases": {"Rayen's Beak": "Raven's Beak"}
}
```
- **`aliases`** ใช้แก้ชื่อที่ OCR อ่านผิด หรือบอกว่าชื่อที่โดนตัดคือไอเท็มไหน
  เช่น `"Dark scroll for Two-handed Swor": "Dark scroll for Two-handed Sword for ATT 70%"`
- เซฟแล้วรัน `python report.py` รายงานจะใช้ชื่อใหม่กับ**ข้อมูลย้อนหลังทั้งหมด**ทันที เพราะ `fm.db` เก็บชื่อตามที่ OCR อ่านได้ไว้เสมอ

### `review_names.csv`
รายชื่อที่จับคู่ไม่ได้ (`unmatched`) หรือเข้าได้หลายตัว (`ambiguous`) เปิดด้วย Excel ได้
- ดูคอลัมน์ `name` แล้วเพิ่มเข้า `aliases` หรือ `items` ใน `items.json`
- ชื่อที่จับคู่ได้แล้วจะหายจากไฟล์นี้เองตอน ingest รอบถัดไป
- ในรายงาน ชื่อที่ยังกำกวมจะลงท้ายด้วย `…` (ระบบไม่เดาให้)

### เช็คว่าชื่อจะถูกจับคู่ยังไง
```
python normalize.py "Scroll for One-Handed Axe for Ac" "Rayen's Beak"
```

### รายชื่อไอเท็มอ้างอิง
- `items.json` ส่วน `"items"` คือรายชื่อจริงของเซิร์ฟเวอร์ (ไอเท็มที่ไม่ใช่ cash ราว 3,900 ชื่อ) นำเข้าจาก `osm_item_index.json` (ดูหัวข้อถัดไป)
- `icons.py` ใช้ ID จาก `osm_item_index.json` หารูปไอคอนจาก maplestory.io ซึ่งเป็นแหล่งรูปเดียวกับที่เว็บของเซิร์ฟเวอร์ใช้
- ส่วน `"gms"` (รายชื่อ GMS v83) ปิดไว้แล้ว เพราะเซิร์ฟเวอร์ตั้งชื่อต่างจาก GMS เช่น "ATT" กับ "Attack" ถ้าอยากเปิดใช้อีกครั้ง ให้รัน `python normalize.py --import-gms`
- ลำดับความสำคัญ: `"items"` สูงสุด รองลงมาคือ `"auto"` (ชื่อที่ระบบเรียนรู้จากคลิป)

### นำเข้ารายชื่อจากเว็บของเซิร์ฟเวอร์ (ถ้าต้องการ)
เว็บ https://www.oldschoolmaplegame.com/items มีระบบกันบอท โปรแกรมดาวน์โหลดเองไม่ได้ ต้องเซฟจากเบราว์เซอร์
หน้ารายการของเว็บดึงไอเท็ม**ทุกหมวด**จากไฟล์เดียว จึงเซฟไฟล์นั้นตรงๆ ได้เลย:
1. เปิด https://www.oldschoolmaplegame.com/api/item-index ในเบราว์เซอร์ (จะเห็นข้อความ JSON ยาวๆ)
2. กด **Ctrl+S** เซฟเป็น `osm_item_index.json` ในโฟลเดอร์นี้
3. รันคำสั่ง:
   ```
   python normalize.py --import osm_item_index.json
   python report.py
   ```
หน้าเว็บที่เซฟด้วย Ctrl+S (`.html`) ก็นำเข้าได้ แต่จะได้แค่ 120 ชื่อแรกที่แสดงบนหน้า

### กติกาการจับคู่ชื่อ
- **คำสำคัญต้องตรงกันทุกตัว:** ตัวเลขและ %, STR/DEX/INT/LUK/ATT/HP/MP, Dark, Magic, Jump, Speed, Accuracy และคำสั้นๆ
  ระบบจึงไม่รวม "Scroll for Cape for STR 60%" กับ "...INT 60%" หรือ "Dark scroll" กับ "Scroll" เข้าด้วยกัน
- **คำอื่นเพี้ยนได้เล็กน้อย:** เผื่อ OCR อ่านพลาด เช่น "Rayen's Beak" → "Raven's Beak"
- **scroll ที่ชื่อโดนตัด ระบบดู % จากสีไอคอน:** 10% เหลือง, 60% แดงส้ม, 100% ฟ้า, Dark 30% ม่วง, Dark 70% เทา
  เช่น "Scroll for Overall Armor for INT 1" ไอคอนสีเหลือง → "...INT 10%" (ใช้ได้เมื่อเหลือชื่อที่เข้าได้ตัวเดียว)
- **ชื่อที่โดนตัดจนเข้าได้หลายตัวจะไม่เดา:** เช่น "Scroll for Two-handed Axe for" จะขึ้น `ambiguous` ในไฟล์ review

## ตรวจความแม่นยำ (ทำเมื่อสงสัย)
```
python verify_sample.py "<คลิป>.mp4" --out "results\<คลิป>" -n 20
```
ได้รูปใน `results\<คลิป>\verify\` แต่ละรูปมีภาพแถวจากคลิปจริง วางคู่กับข้อความที่ OCR อ่านได้
ดูรวมทีเดียวได้ที่ `sheet.png`

## ไฟล์ในโฟลเดอร์

| ไฟล์ | หน้าที่ |
|---|---|
| `run.bat` | ลากคลิปมาวาง: OCR → ingest → report |
| `fm_ocr.py` | อ่านคลิป → `items.csv` (`python fm_ocr.py <video> --out <dir> [--fps 4]`) |
| `fm_qty.py` | อ่านตัวเลขจำนวนชิ้นบนไอคอน (เทียบแม่แบบตัวเลข) |
| `verify_sample.py` | สุ่มแถวมาเทียบกับภาพจริง |
| `ingest.py` | บันทึก `items.csv` ลง `fm.db` และเรียนรู้ชื่อไอเท็ม |
| `normalize.py` | จับคู่ชื่อไอเท็มกับ `items.json` |
| `report.py` | สร้าง `report.html` |
| `icons.py` / `icons\` | รูปไอเท็มจาก maplestory.io (GMS v83) โหลดครั้งแรกครั้งเดียว ครั้งต่อไปใช้ไฟล์ในเครื่อง ถ้าไม่มีเน็ตก็ยังสร้างรายงานได้ แค่ไอเท็มใหม่จะไม่มีรูป |
| `fm.db` | ฐานข้อมูลราคาทั้งหมด (SQLite) **ควรสำรองไว้** |
| `items.json` / `review_names.csv` | รายชื่อไอเท็ม / ชื่อที่รอตรวจ |

**ความหมายของคอลัมน์ใน `items.csv`**
- `price` คือราคาต่อชิ้น
- `qty` คือจำนวนที่เหลือในร้าน (0 = ขายหมด)
- `unit_price` = `price` (ว่างถ้าขายหมด)

## แก้ปัญหา

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|

| ต้องการเริ่มฐานข้อมูลใหม่ | ลบ `fm.db` (ควรสำรองก่อน) แล้วรัน ingest ใหม่จากโฟลเดอร์ใน `results\` |
| `python` ไม่พบคำสั่ง | ติดตั้ง Python 3.12 และ `pip install -r requirements.txt` และต้องมี Tesseract ที่ `C:\Program Files\Tesseract-OCR` |
